# Windows Screentime

> *"Because scrolling until 3 AM isn't a personality trait."*

Welcome to the ultimate solution for staring at screens slightly less on Windows, You can see how many minutes your child has spend on his/her computer!

---

## Why Another Screen Time App?

The screentime libary on Windows is small, so a little open-source project is born!

Standard built-in screen time tools are great, but they often lack unbreakable boundaries, there is always a button "15 more minutes." wich doesn't help it

---

## Features

- 📊 **Real-time Dashboard:** Crisp visualization of daily activity.
- ⏱️ **Intelligent Interventions:** Customizable times for locks and exceptions.
- 🛡️ **Secure protection** All passwords are saved and encrypted and "the wall" is unbreakable

## 🛠️ Getting Started


### Installation

1. **Download the latest installer**
    See the releases page

2. **Set a secure password**
    You will need this later on

3. **Restart your computer**
    This is needed for it to work

4. **Enter your email**

5. **Enter a password again**
    This is needed for the top security
